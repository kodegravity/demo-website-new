# Quantorule Website

Marketing website for Quantorule, an IT consulting and custom software development company serving medium-sized businesses.

Quantorule helps teams plan, build, deploy, and maintain reliable digital systems including web applications, cloud infrastructure, automation workflows, integrations, dashboards, and long-term technical support.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Vercel
